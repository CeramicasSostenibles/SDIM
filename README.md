SDIM

Programa para diseñar baldosín cerámico a partir del suelo.

SDIM recibe los resultados de laboratorio de un suelo o relave y entrega:

- la clasificación del suelo,
- la pieza en 3D,
- la mezcla sugerida (relave, caolín, feldespato y agua),
- las curvas de secado y de horno,
- la comparación de los ensayos con la norma NTC 919,
- un informe final en PDF.

Descargar

Descargue el instalador (SDIM-1.1.exe) en la sección [Releases].

Para instalarlo y usarlo, abra la Guía rápida ("Guia_rapida_SDIM.txt").

Contenido

- "Guia_rapida_SDIM.txt" cómo instalar y usar el programa.
- "codigo_fuente" el código del programa (Java).
